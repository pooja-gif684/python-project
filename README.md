# python-project

Each exercise is in its own Python file and can be run with `python <filename>`.

- `task_01_calculator.py` — arithmetic operations
- `task_02_number_checks.py` — even/odd and divisibility checks
- `task_03_result.py` — pass, fail, or distinction
- `task_04_student_eligibility.py` — marks, attendance, and backlog eligibility
- `task_05_login.py` — username and password check
- `task_06_discount.py` — purchase discount and payable amount
- `task_07_access_control.py` — access rules
- `task_08_skill_check.py` — acquired skill lookup
- `task_09_calculate.py` — operator-based calculator
- `task_10_placement.py` — placement eligibility and candidate category
